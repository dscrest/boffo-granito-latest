## Anti-Patterns Verdict

**LLM assessment:** The visual system is disciplined — one token sheet, one table idiom, one modal chrome, calm density; not template slop. The slop lives in the *data*: whole panels of fabricated prototype figures (fake truck/dock/seal, fake people in Activity timelines, fake Documents with KB sizes, fake KPIs) render in the same visual register as live DB numbers. A Stripe-fluent user would trust the shell and be betrayed by the drawer's Timeline citing "Ramesh, 15 May · 14:32" for an order created yesterday. Minor decorative residue: gradient icon tiles in df-head, gradient section-title stripe, 3px accent stripes.

**Deterministic scan:** 18 findings, all `side-tab` (no other rule fired). 4 true positives — decorative accent stripes on form/info cards (SalesPersons.tsx:192, Users.tsx:150, Masters.tsx:170, Production.tsx:68); 4 borderline — accent stripes on bulk-selection action bars (Containers.tsx:200, DesignMaster.tsx:315, Masters.tsx:314, Pallets.tsx:205); 10 conventional status stripes on error/warning surfaces (incl. shared `.error-card` styles.css:1610, FitSuggest amber banner) — classified false-positive/deliberate per prior decision. Detector and review agree the decorative residue is restrained; the detector cannot see the fabricated-data problem, which the review rates the dominant issue.

**Visual overlays:** skipped — no browser automation available this session.
